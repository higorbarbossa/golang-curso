# Estudos de Go

Repositório com exercícios e exemplos desenvolvidos durante meus estudos de Go (Golang).

## Curso

Estou acompanhando o curso [Aprenda Golang do Zero - Desenvolva uma Aplicação Completa](https://www.udemy.com/course/aprenda-golang-do-zero-desenvolva-uma-aplicacao-completa/).

## Objetivo

Praticar os conceitos apresentados no curso e registrar minha evolução na linguagem Go.

## Executar os exemplos

Com o Go instalado, entre na pasta do exemplo e execute:

```bash
go run .
```

Os exemplos podem ser organizados em pastas conforme o conteúdo estudado.
